# 卡CG：审核窗口期「注册即通过」开关（`purchaser_auto_approve`）

> 模式：**代码开发**。基线 HEAD = `7c48313`（开工前先 `git log --oneline -1` 核对）。
> 一张卡只做「改 + 最小自测」；改动**只许动下面 5 个文件**，不许顺手重构。

## 为什么要做（背景）

小程序正在走微信审核。审核员的体验路径是：一键登录 → 填注册表单 → 提交 → **停在「审核中」** →
而 `cart.service.ts` / `order.service.ts` 的 `assertActivePurchaser()` 硬要求 `accountStatus=2`，
**AI 下单页进不去**（现在会显示「账号注册并审核通过后可用」空态）→ 会被判「功能无法体验」再驳一次。

所以需要一个**默认关闭、可一键开关**的临时通道：审核窗口期打开 = 新注册的采购方**直接通过审核**（`accountStatus=2`），
审核（版本 + 类目）全过后**立刻关掉**，恢复人工审核。
