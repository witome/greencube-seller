## 一、一句话

把已经建好的"手机专线"能力显示出来：后台催单台看得出**专线在不在线、每通走哪条通道、接没接通、响了几秒**；供应商端两处提示他**存备注、别回拨**。

## 二、上游接口（**已就绪，直接用**）

| 接口 | 本次新增/可用的字段 |
|---|---|
| `GET /admin/supplier-notify/config` | `channel: 'phone'\|'aliyun'\|'off'`、`ringSeconds`、`hangupAfterAnswerSeconds`、`gatewayPhoneNo`、`gateway: {online: boolean, lastHeartbeatAt: string\|null}`（`online` = 180 秒内有心跳） |
| `PUT /admin/supplier-notify/config` | 同上四项可写；非法值（如 `ringSeconds=0/99`）→ **HTTP 400 + 业务码 1001** |
| `GET /admin/supplier-notify/records` | 每行新增 `channel`、`dialId`、`durationSec`；`result` 取值含 `dispatched` / `connected` / `no_answer` / `failed` / `dry_run` / `initiated` 等 |
| `GET /supplier-notify/me`（小程序） | 新增 `reminderPhoneNo: string\|null`（提醒专号）、`serviceHotline: string\|null`（客服号） |

## 三、要做的（白名单：**只许动这几个文件**）

### A. 运营后台 · 催单台 `admin-web/src/views/order/Reminder.vue`
> 该页**已存在**（卡BN-2 交付），本次是**增补**，不要重写整页、不要动已有列表列与「已处理」逻辑。
1. **顶部加"手机专线"状态**：读 `config.gateway.online` 与 `lastHeartbeatAt` —— 在线显示「手机专线：在线（xx 前心跳）」（绿色），离线显示「手机专线：离线，请人工跟进」（红色/警示色）；`lastHeartbeatAt` 为空时显示「从未上线」。
2. **台账抽屉每行补三项**：通道（`phone`→「我的手机」、`aliyun`→「云语音」、其他→原样）、是否接通（`result==='connected'`→「已接通」）、时长（`durationSec` 秒，为空显示 `—`）。
3. **结果文案映射补新值**：`dispatched`→「已派发」、`connected`→「已接通」、`no_answer`→「未接听」、`failed`→「拨打失败」；**原有映射（dry_run / initiated 等）保持不动**。
4. **设置卡加四项**（保存仍走既有 `PUT /admin/supplier-notify/config`，与现有字段一起提交）：
   - 通道：单选「手机专线 / 云语音 / 关闭」；
   - 响铃秒数：数字输入，**1~30**；
   - 接通后挂断：数字输入，**0~30**；
   - 提醒专号：文本输入，≤20 字符（**仅展示与复制用**，不是拨打目标）。
   - 后端 400 时把错误信息原样提示出来（别吞掉）。

### B. 供应商端小程序 · `frontend/src/subpkg-supplier/pages/mine.vue`
