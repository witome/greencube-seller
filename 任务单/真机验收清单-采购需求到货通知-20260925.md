## 一、🔒 只有大辉能做的（前置，不做后面都验不了）

### 1. 公众平台申请「到货通知」订阅消息模板

路径：微信公众平台 →「小程序」→ 功能 → 订阅消息 → 选用/申请模板

- 标题建议：**到货通知**
- 字段建议：**商品名称 / 到货时间 / 备注**（三个字段，别多别少，多了要改字段映射）
- 类目按主体选（生鲜 / 电商）
- **拿到模板 id 后交给 Hermes**，由 Hermes 写进**生产** `.env` 的 `WX_SUBSCRIBE_TMPL_DEMAND=<模板id>`，然后重启后端。

> ⚠️ 我这一轮**没有、也不许**动生产 `.env`。模板 id 也不许写死在代码里 —— 现在是「只在配置里读，
> 没配就按钮隐藏 + 接口给人话提示」。

如果模板字段名不是 `thing1 / time2 / thing3`，同时改这一行（默认值就是这个）：

```
WX_SUBSCRIBE_TMPL_DEMAND_FIELDS='{"thing1":"{name}","time2":"{time}","thing3":"{note}"}'
```

可用变量：`{name}` 菜名 · `{time}` 到货时间 · `{note}` 备注。

### 2. 生产 `.env` 新增两行（Hermes 执行）

```
WX_SUBSCRIBE_TMPL_DEMAND="<公众平台拿到的模板 id>"
WX_SUBSCRIBE_TMPL_DEMAND_FIELDS='{"thing1":"{name}","time2":"{time}","thing3":"{note}"}'
```

`WX_API_BASE` **生产必须留空**（留空 = 走 `https://api.weixin.qq.com`）。

## 三、已知限制（不是 bug，二期再说）

1. **短信通知**按口径留到二期，这一轮不做。
2. **客户自己在小程序里删除需求**留二期，这一轮只做「登记 + 通知」。
3. **客户侧搜索无结果**上报（口径 1④）留二期。
4. 近似词**不自动合并**（「荷兰豆」和「LaLa豆」会是两条）—— 由后台「合并到…」手动并，
   这是**故意**的：自动猜同义词容易把两样菜并成一条，采购照着买就买错了。
5. 模板未配置时，后台「到货通知」按钮点了会给「运营还没配置到货通知模板」的提示，
   小程序端按钮**直接隐藏**（不让客户点一个注定失败的按钮）。
