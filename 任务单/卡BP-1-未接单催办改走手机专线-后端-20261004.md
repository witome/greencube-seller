## 一、一句话

把现有"扫描到就调阿里云语音"改成"扫描到就等本地网关来取"：新增 **派发 / 回报 / 心跳** 三个网关接口 + **四个配置项**，扫描逻辑不再直接拨打。

## 二、现状（已核对，**别重做**）

- 全部逻辑在 `backend/src/modules/supplier-notify/`（`supplier-notify.service.ts` / `.controller.ts` / `.module.ts` / `vms.adapter.ts`）。
- 配置：`platform_config` 键 `supplier_ack_reminder`，字段 `{enabled, thresholdMinutes, secondGapMinutes, maxCalls, quietEnabled, quietStart, quietEnd, launchAt}`；键缺失时用代码里的默认值，`enabled` 默认 **false**。
- 台账：**不是数据表**，写在审计日志 —— `action='SUPPLIER_NOTIFY_CALL'`，payload `{orderId, supplierId, mode:'auto'|'manual', result, callId, note, dryRun, at}`；后台"记录"抽屉读它。
- 现在扫描命中 → `dialTts(phone)`（阿里云；四把 `ALIYUN_VMS_*` 未配 ⇒ dry-run）。
- 号码来源 `Supplier.user.phone`（**生产库 4 家供应商全都有**；为空则跳过、只提醒运营）。

## 三、要做的（白名单：**只许动这几个文件**）

### 1. `supplier-notify.service.ts`
- 扫描命中后**不再调 `dialTts`**，改成"只登记待派发"；现有七条判定（`enabled` / `maxCalls<=0` / 阈值 / 第 2 通间隔 / 免打扰 / `ackCallEnabled` / 号码为空）**原样保留**。
- 新增 **`pendingDial(limit)`**：
  - 在**一个事务**里挑出最多 `limit` 条候选 —— 判定逻辑与扫描**共用同一个私有方法**，**别写第二份**；
  - 每条：写审计 `SUPPLIER_NOTIFY_CALL`，payload `{mode:'auto', channel:'phone', result:'dispatched', dialId, at}`，并 `remindCount += 1`、`lastRemindAt = now`（沿用现有写入方式）；
  - 返回 `[{dialId, orderId, supplierId, phone, supplierName, shopName, minutesUnacked, ringSeconds, hangupAfterAnswerSeconds}]`；
  - `dialId = \`${orderId}_${supplierId}_${Date.now()}\``。
- 新增 **`reportResult(dto)`**：写审计 `SUPPLIER_NOTIFY_CALL`，payload `{mode:'auto', channel:'phone', dialId, result, durationSec, cause, at}`；`result ∈ 'dispatched' | 'connected' | 'no_answer' | 'failed'`。
- 新增 **`heartbeat()`**：把 `{at}` 写进新键 `platform_config.supplier_notify_gateway_state`（Json）。
- **`getConfig()` / `updateConfig()` 增四个字段并校验**：
  - `channel`：`'phone' | 'aliyun' | 'off'`（默认 **`phone`**）；
  - `ringSeconds`：整数 **1~30**（默认 5）；
  - `hangupAfterAnswerSeconds`：整数 **0~30**（默认 2）；
  - `gatewayPhoneNo`：字符串、可空、≤20 字符（仅用于展示与复制）。
  - 非法值 → **400**（沿用现有校验形态，自测里写实测值）。
- `list()` 返回体增加 `channel` 与 `gateway: {online, lastHeartbeatAt}`；`online` = 最近一次心跳在 **180 秒**内。
- `channel === 'off'` ⇒ `pendingDial` 返回空数组；`channel === 'aliyun'` ⇒ **保持原 `dialTts` 行为**（旧路径不许删）。

### 2. 新增 `supplier-notify-gateway.controller.ts`（含令牌守卫）
- 三个路由：`GET /supplier-notify-gateway/pending-dial?limit=5`、`POST /supplier-notify-gateway/report`、`POST /supplier-notify-gateway/heartbeat`。
- **守卫**：请求头 `x-gateway-token` 必须等于 `process.env.SUPPLIER_NOTIFY_GATEWAY_TOKEN`，且该 env **必须非空**；否则一律拒绝（实测写清 HTTP 码与响应体）。**不要挂 `@Roles(ADMIN)`** —— 网关不是运营账号，别复用那套守卫。
- 号码**只允许在 `pending-dial` 的响应里**出现明文（网关要拨号）；写审计/日志一律 `maskPhone`。

## 四、验收（自测脚本必须打印下面 10 条的**实测值**）
