## B. 主路径（必须先跑这条）

| # | 操作 | 预期 | 实际 |
|---|---|---|---|
| B1 | 在「智能下单助手」页，**按住**左下角话筒，清楚地说：**「土豆50斤，大白菜20斤」**，说完**松开** | 录音浮层消失 → 输入框回填识别原文 → 自动出一条 AI 气泡 + 一张「📋 订单草稿已生成」卡 | |
| B2 | 核对草稿卡里的**商品名** | 与库内在售商品名一致：**土豆**、**大白菜**（不是「马铃薯」，也不是演示商品「白菜001」） | |
| B3 | 核对草稿卡里的**数量 / 单价 / 合计** | 库里价：**大白菜 1.28 元/斤**、**土豆 1.56 元/斤**。按 50 斤 / 20 斤直算应是：土豆 `50 × 1.56 = 78.00`、大白菜 `20 × 1.28 = 25.60`、**合计 103.60**。⚠️ 若该商品是「按颗/按规格」的称重商品（卡里会出现「💡 称重商品以实际称重为准，多退少补」），则数量按规格换算、金额**以库里当场价为准** —— **只核对「单价和名称与库内一致」，不要用上面的数字硬卡** | |
| B4 | 点卡片上的「🔗 查看并确认订单 ›」 | 跳到订单确认页，商品/数量/日期可改。**到这一步为止都没有真的下单**（成单必须人工再点一次确认） | |

> B 段只要「出草稿卡 + 名称单价与库一致」就算主路径通。**不要**在验收里点「确认下单」造测试单。

## C. 边界（6 条，逐条跑）

| # | 操作 | 预期 | 实际 |
|---|---|---|---|
| C1 🔒 | **首次授权**：用一个**从没给过麦克风权限**的微信（或先在设置里关掉麦克风）按住话筒说话 | 弹**系统**授权弹窗。点「允许」后**不会自己开始录音**，而是提示「**麦克风已开启，请按住话筒说话**」→ 再**按住**话筒说话，正常出草稿卡。⚠️（P1 已修，commit `1e6f1e0`：修前表现为「点了允许后即使手已松开还在录、要再点一下话筒才停」——**若仍复现，记下现象**） | |
| C2 🔒 | **拒绝后引导**：先拒绝麦克风权限，**再按住话筒**说话 | 弹出自定义框「需要麦克风权限 / 语音下单要用麦克风听懂您说的话，请在设置里打开」→ 点「**去设置**」能跳到小程序的**权限设置页**（手机微信里也可走：小程序右上角「···」→「设置」→「麦克风」）。设置里打开后再按住话筒 → **能正常录音出草稿**。若设置页里**仍未打开**就返回 → 应弹「没有麦克风权限，无法语音下单」，**不卡死、不白屏** | |
| C3 | **说半句就松手**：按住话筒只说半个字/不出声（如刚开口就松手，或按住 1 秒不说话） | 浮层消失，提示「**没听清，请再说一遍**」，页面正常可用 | |
| C4 | **说无关内容**：按住话筒说「今天天气怎么样」 | AI 气泡回「**抱歉，暂时没识别出可下单的商品，换个说法试试～比如「土豆10斤」**」，**不崩、不白屏**（不会出草稿卡是对的） | |
| C5 | **录音中切走再回来**：按住话筒说话 → **不松手**，另一只手把小程序切到后台（或返回上一页）→ 再回到「智能下单助手」页 | 回来后**不应还在录音**（浮层不在、麦克风不占用），且**不应弹任何报错提示**。⚠️（P2 已修，commit `1e6f1e0`：修前会误弹「语音识别失败(-30012)」——**若仍弹，记下现象**） | |
| C6 | **等待表现**：松手后盯着从「松手」到「草稿卡出现」这一段 | 浮层**立即**消失、输入框回填识别原文、发送按钮置灰。**这段没有 loading 提示**（当前设计如此）。正常情况下几秒内出草稿卡；后端大模型若超过约 8 秒会自动降级到规则版，**仍会出卡**。若**超过 15 秒仍无任何结果** → 记下现象 | |
