## 一、要做什么（严格照原型逐屏对齐）

### A. 供应商端 `frontend/src/subpkg-supplier/pages/goods-manage.vue`

1. **「计量方式」chip 文案去「斤」**：`称重（斤）` → **`称重`**（`固定规格` 不变）。本文件里所有出现处都要改（提交新品表单 + 两个编辑弹层）。
2. **新增「单位」行**，位置在「计量方式」行**正下方**：
   - **平铺可点 chip**（照抄同页「商品分类」那套 `.chip-group` / `.chip` 样式），**禁止下拉、禁止 `<picker>`**；
   - 选项来自 `GET /units`（只返回启用中的，按 sort），默认选中 `斤`；
   - **没有「其他 / 手填」入口**；
   - 三个表单都要加：**提交新商品** / **编辑商品（变更审核）** / **编辑待审商品**。编辑弹层打开时用当前值回显。
3. **placeholder 随单位联动**：供货价 → `如 120（元/{单位}，提交后审核）`；日可供量 → `如 50（{单位}）`（示例值按原型：瓶 → 120 / 50，其余沿用现状 2.20 / 200）。
4. **提交时带上 `unit`**：三处 submit 都要把选中的单位传进请求体（后端 卡BV-1 已按「启用 ∪ 当前值」校验）。
5. **已停用单位的回显兜底**：编辑一个当前单位已被停用的老商品时，chip 列表里要**保留该单位并标注「（已停用）」**，不许显示成没有选中。

### B. 运营后台：新增「计量单位」维护页

- 新页面（照原型画面2：侧栏挂在**「商品管理」**分组下），路径自定但要在 `admin-web/src/router` 与侧栏菜单里登记。
- 内容：**四列** `排序 / 单位名称 / 状态 / 操作`；表头区 `＋ 新增单位` 按钮；表头上方一行说明「停用后不再出现在新建商品与供应商端，老商品与历史订单照常显示原单位」。
- 每行操作：**上移 / 下移**（改 sort，调完刷新顺序）+ **停用 / 启用**；**不许有「删除」**。
- `＋ 新增单位` 弹窗：字段 `单位名称`（必填）、`排序`（选填，数字越小越靠前，留空追加到末尾）、`状态`（默认启用）；**重名 → 输入框下红字 `该单位已存在，请换一个`**，不许提交。
- 按钮/表格/弹窗一律用 `el-*`（照原型与后台既有视觉规范）。

### C. 运营后台商品编辑的单位栏（`admin-web/src/views/goods/GoodsManage.vue:91` 附近）

- 自由输入框 → **`el-select` 下拉**，选项来自 `GET /units`；
- 下拉下方灰字提示：**「没有想要的单位？到『计量单位』页添加」**；
- **兼容**：编辑老商品时，若该商品当前单位已被停用，下拉里要**保留该项并标注 `（已停用）`**，不许显示空白。

### D. 买家端

- **零改动**。商品卡 / 详情 / 购物车 / 订单 / 售后 / 供应商单据本来就都读同一个 `unit` 字段——不许借这次去动它们。
