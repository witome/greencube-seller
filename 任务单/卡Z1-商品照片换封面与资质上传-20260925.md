## 接口口径（写死）

`PUT /supplier-goods/:productId/cover`，body `{ cover: string }`：

- **免审即时**：直接更新 `product.cover`，**不许**创建 applications 申请、**不许**走审核队列（照片不涉及价格/数量口径）。
- **归属校验**：必须是当前供应商名下商品（`product_supplier_link` 存在且 `supplierId` 对得上），否则 404。
- **地址白名单**：`cover` 只接受本站上传的地址 —— 以 `/uploads/` 开头，或以生产域名开头的 http(s) URL（`https://api.hsfresh.com/uploads/…`）；其它一律业务错误（400 类）「封面地址不合法」。**防外链、防注入**。
- **留痕**：写一条 `audit_log`（记录 operator=供应商用户、productId、变更前后 cover 值），action 名自取但要能看懂（如 `SUPPLIER_COVER_UPDATE`），格式对齐 `VOICE_SUPPLIER_REPORT` 那条的写法。

## 前端行为（严格照原型屏 ①②③⑦）

- 商品行左侧：`<image mode="aspectFill">` 显示 `cover`；**无 cover 回退成现在的 emoji 图标**（不许出现白块/破图）。
- 缩略图右下角一个小相机角标（暗示可点）。
- 点缩略图 → `uni.showActionSheet`：**拍照 / 从相册选择 / 取消** → `uni.chooseImage`（按选择传 `sourceType`）→ `uploadPhoto()` 压缩上传 → 调新接口 → 成功后就地替换该行缩略图 + 轻提示「封面已更新（已生效）」。
- **上传中**：该缩略图上盖转圈，**期间禁止重复点击**（防连点产生多次上传/并发写）。
- 失败要有可读提示（网络失败 / 图片过大 / 地址不合法），不许静默失败。
- 「提交新商品」表单：封面区（点击选图，可重选，显示已选缩略图）+ **资质证明**区（复用 `pickPhotos`/`uploadPhoto`，上限 5 张，可预览可删）→ 提交时 `cover` 与 `images` 一并带上（`apply` 需要接收 `cover`）。现状那行「＋ 上传检疫合格证」是**点不动的死文案**，要真接上。
