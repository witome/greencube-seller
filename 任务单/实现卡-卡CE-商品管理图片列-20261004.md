## 三、怎么做

### 1) 后端：`listProducts` 每行补两个字段（契约**只增不改**）
在现有返回对象里增加（既有键一律不动、不改语义）：
```js
cover: p.cover ?? null,
images: Array.isArray(p.images) ? p.images.filter((x) => typeof x === 'string' && x.trim() !== '') : [],
```
（与 `pending()` 同口径：`images` 必须归一为数组、滤空，前端才能直接 `v-for`；`cover` 允许为 null。）

### 2) 后台：`GoodsManage.vue` 加「图片」列
- 位置：放在「商品」列**右侧**（第 2 列），`label="图片"`、`width="150"`，不加 `fixed`。
- 渲染**照 GoodsAudit.vue 卡CA 那份实现**（同一套写法，不许自创）：
  - 封面：`44×44` 缩略图（有 `cover` 才渲染；用 `el-image`，`fit="cover"`）；
  - 资质：`22×22` 最多 2 张，超出合并为 `+N`（可点）；
  - 所有缩略图**共用一个预览列表**（`el-image` + `preview-teleported` + `:preview-src-list` + `:initial-index`），点第 N 张就从第 N 张开始看大图；
  - 图片地址用后台既有的 `fullUrl()` 约定（照 GoodsAudit.vue 里怎么拼就怎么拼）；
  - **无任何图的行显示占位 `—`**，绝不白块/破图。
- 数据只来自本次新增的 `row.cover` / `row.images`，**不许为图片再调别的接口**。
- **不许改**：筛选栏、分页、`openCreate/openEdit/save/toggleStatus` 等既有逻辑与弹层。
