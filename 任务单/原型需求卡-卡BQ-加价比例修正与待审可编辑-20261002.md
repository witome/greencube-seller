## 一、这张卡的由来（背景，别改需求）

复核时实测发现的三个问题，大辉 2026-10-02 拍板要修：

1. **加价比例"改不动"**（真 bug）：
   - 后台商品审核页点「通过」时**每次都把加价比例传给后端**（默认 0.3），后端收到就把它标成「单品」比例；
   - 而后端规则是 **单品 > 供应商 > 分类 > 全局**，单品档的商品永远跳过档位变更 → 运营后来改供应商比例，商品价格不动；
   - 且后台**没有"取消单品、恢复继承"的入口**。
2. **采购商被恶意注册**：待审队列只有「通过/驳回」，恶意注册会一直堆在队列里反复提醒。
3. **待审新品不能编辑**：供应商提交的新品在「待审核/已驳回」状态下只有删除按钮，编辑是灰的；后端也硬拦（"仅已上架商品可发起变更"）。

## 三、要出的屏（4 屏，每屏都要把下面列的状态画全）

### 屏1｜运营后台 · 加价设置（对应代码 `admin-web/src/views/pricing/Pricing.vue`）
必须出现：
- 顶部说明条：`生效优先级：单品 > 供应商 > 分类 > 全局默认`
- 三块配置区：**全局默认 / 按分类 / 按供应商**，每块列表带「比例」列 + 「保存」按钮
  - 状态A（**未配置**）：比例列显示灰字「未设置」——这就是现在的真实库状态（配置表是空的）
  - 状态B（已配置）：显示 `30%` + 小字「继承生效中」
- 商品表格列：商品名 / 供货价 / **比例来源** / 加价比例 / 销售价 / 操作
  - 「比例来源」列的三种取值要各画一行：`单品`（橙色标签）、`供应商`、`全局默认`（灰标签）
- **新增**：对「比例来源 = 单品」的行，操作列加「恢复继承」按钮
- **新增**：点「恢复继承」弹二次确认抽屉/对话框，文案：
  - 标题：`把「XX」恢复为继承档位比例？`
  - 正文：`恢复后这个商品不再固定「单品」比例，改按 供应商 > 分类 > 全局 生效；销售价会随下次重算联动。`
  - 按钮：`再想想` / `确认恢复`
- **改**：保存比例时的影响范围弹窗里，「应用到现有商品」**默认勾选**，并给一行灰字说明：
  `勾上会按新比例重算在售商品销售价（单品单独设过的会跳过）`
- 状态C（重算完成反馈）：toast/提示条 `已保存配置；重算在售商品 N 件，跳过单品 M 件`
- 空态：供应商列表为空 → `暂无供应商`

### 屏2｜运营后台 · 商品审核弹窗（对应代码 `admin-web/src/views/goods/GoodsAudit.vue`）
必须出现：
- 通过弹窗里的「加价比例」输入框改成**可留空**，两种状态各画一张：
  - **留空态**（默认）：输入框空 + 灰字 `留空 = 按 供应商 > 分类 > 全局 自动计算（当前会算出 30%）`；右侧实时显示算出的销售价
  - **手动填写态**：填了 0.5 → 橙色提示 `手动填写会把此商品固定为「单品」比例，之后调整供应商/分类/全局比例不会影响它`
- 审核通过后的结果提示：`已通过。该商品按「全局默认 30%」定价` 或 `已通过。该商品已固定为「单品 50%」`
- 加价比例的单位/写法照现状（小数，如 0.3 = 30%）

### 屏3｜运营后台 · 采购商审核（对应代码 `admin-web/src/views/buyers/`）
必须出现：
- 顶部**页签**：`待审核 (3)` / `已忽略 (2)` / `全部`——角标只算「待审核」
- 待审行操作列：`查看` / `通过` / `驳回` / **`忽略`**（忽略用灰/中性色，不要红色，避免和驳回混淆）
- 点「忽略」的二次确认：
  - 标题：`忽略这条注册？`
  - 正文：`忽略后该账号不再出现在待审核列表、无法下单，也不给申诉入口。适合恶意注册。`
  - 按钮：`再想想` / `确认忽略`（确认键用中性色）
- 「已忽略」页签里的行：状态标签灰字 `已忽略`，操作只留 `查看`
- 超时提示照现状保留（待审超 24 小时的红字提醒）
- 空态：`暂无待审核注册`

### 屏4｜供应商端 · 商品管理（对应代码 `frontend/src/subpkg-supplier/pages/goods-manage.vue`）
必须出现：
- 商品列表里 **「待审核」和「已驳回」两行都要把「编辑」点亮**（现在这两态编辑是灰的、只给删除）——这是本屏重点，要和「在售」行的编辑长得一样可点
- 待审核行：`✏️ 编辑` + `🗑 删除`
- 已驳回行：`✏️ 编辑` + `🗑 删除`，并保留驳回原因红字
- 点编辑进入的编辑弹层（画这一屏的弹层）：
  - 标题：`✏️ 编辑待审商品`
  - 副标题：`还没审核通过，改完仍是这一条，不会多出一条待审`
  - 可改字段：商品名称 / 商品分类（只能选已授权分类）/ 计量方式 / 供货价 / 日可供量 / 商品备注（≤12 字）/ 封面图
  - 底部按钮：`取消` / `提交修改`
- 提交后的反馈两种：
  - 待审核态改完：toast `已更新，仍在等待审核`
  - 已驳回态改完：toast `已重新提交审核`
- 兜底态（必画）：编辑提交时该商品**刚好被运营审核通过**了 → 提示 `该商品已审核通过，请用「变更申请」修改`
- 底部的语音报量入口照现状保留
