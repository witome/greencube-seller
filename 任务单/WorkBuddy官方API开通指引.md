# WorkBuddy 官方 API 开通指引(10 分钟,只有你能做)

**目的**:开通后,三黑就能**一次给你派一批任务**(不再一张一张等),并且**实时看到每个任务的进度、拉产物、失败了自动重派**。

---

## 为什么值得开

| 现在(桌面版) | 开通后(官方 API) |
|---|---|
| 一次一张卡,得等它做完 | **一次排 N 个任务**,并发跑 |
| 进度只能看窗口 | 每个任务的状态/产出**自动回报**给我 |
| 要我点鼠标贴消息 | 我直接调用,不用碰鼠标 |

**两条通道都有用**:
- **云端任务** —— 在腾讯的云沙箱里跑(不需要你的电脑开着),适合独立脚本 / 文档 / 分析这类活
- **本机助理消息** —— 直接驱动**你电脑上这个 WorkBuddy**(就是有代码的那个),适合改绿立方这类必须在本机干的活

---

## 你要做的 6 步

### 1. 打开注册网址并入驻

```
https://open.workbuddy.cn
```

点右上角「**登录**」→ 注册。

⚠️ **首次要实名**:平台原话是「首次注册 WorkBuddy 开放平台需要进行**个人认证或企业认证**,可按需选择其一」→ **个人认证就够**,不用公司资质。

### 2. 进「硬件接入」,点「+ 硬件接入」

⚠️ **控制台里它叫「硬件接入」** —— 既不是文档里写的「第三方应用」,也不是首页那四个(「Buddy应用 / 专家 / 技能 / 连接器」,那些是**往市场上架作品**用的)。

**认准这句话**:点进去后页面写着 ——「**面向硬件设备与合作伙伴开放的 API 能力。创建后可获取 Client ID / Client Secret,并管理所需权限**」。**Client ID / Client Secret 正是我们需要的**,就是它。

路径:**左侧菜单 → 硬件接入 → 右上角「+ 硬件接入」**

⚠️ **【必须先企业认证】** 平台自己的提示原文:

> **「个人开发者无法进行硬件接入,如需接入,请进行企业认证,成为企业开发者」**

(文档站也是分开的两页:`service-categories-individual` / `service-categories-enterprise` —— 「外部应用接入」只挂在**企业**那侧。)

**企业认证三条路(挑最省事的):**

| 方式 | 怎么验 |
|---|---|
| **微信公众号 / 小程序账号快速认证** ⭐ **最快** | 跳转微信授权一下,系统自动校验「营业执照主体」与「微信账号已实名主体」是否一致 —— **不用法人人脸** |
| 腾讯云账号快速认证 | 跳转腾讯云授权,校验主体一致 |
| 企业法人实名认证 | **法定代表人本人扫码做一次人脸核身** |

**准备材料**:营业执照(要 OCR 识别企业名称 / 统一社会信用代码 / 法定代表人姓名)+ 一个对外展示的**开发者昵称**。

> 💡 你已经有小程序,如果**小程序的认证主体就是营业执照主体**,那第一条路最快,几分钟就能过。

应用名随便取,比如 `三黑调度`。

**创建完两件事:**
1. **复制 Client ID / Client Secret**(⚠️ **Secret 只显示一次**)→ 存到桌面 `workbuddy-api.txt`
2. 在它的**权限管理**里勾上第 3 步那 4 项

**参考文档(备查)**
- 快速开始与全流程:<https://open.workbuddy.cn/docs>
- 文档里「第三方应用」页(讲 OAuth 2.1 与 Scope 的):<https://open.workbuddy.cn/docs/third-party-app>

**文档里的原流程**:注册并入驻 → 完成资质认证 → 创建业务类型 → 完善基础信息和能力配置(选 Scope)→ 在测试环境调试 → 提交平台审核

### 3. 只勾这几个权限(最小够用,别多选)

| 权限 | 作用 |
|---|---|
| `user.task.invokable` | 创建并执行**云端任务** |
| `user.task.readable` | 读任务列表/详情(我要看进度) |
| `user.localassistant.invokable` | **给你电脑上的 WorkBuddy 发消息**(这条最关键) |
| `user.profile.readable` | 读基本信息 |

⚠️ **先不要勾** 和积分/兑换码相关的(`user.credit.exchange`)—— 以后确实需要再加。

### 4. 回调地址(redirct_uri)怎么填
填这个就行:

```
http://127.0.0.1:8899/callback
```

(我会在本机起一个临时小服务接它,**只在你授权那一次用**,用完就关)

### 5. 提交审核 → 等通过
状态从「审核中」变成「**已启用**」就可以了(通常不会太久)

### 6. 把 client_secret 存到桌面(⚠️ 只显示一次)

**创建成功时,`client_secret` 会明文显示一次,关掉页面就再也看不到了。**

立刻这样做:
1. **复制它**
2. 在**桌面**新建一个文本文件,命名 `workbuddy-api.txt`,把下面三行填好存进去:

```
client_id=你的应用ID
client_secret=刚才复制的密钥
redirect_uri=http://127.0.0.1:8899/callback
```

3. **别发在微信/对话里**(我不需要你贴给我,我自己从桌面文件读)

---

## 存好之后跟我说一句「存好了」

我会:
1. 从桌面读那个文件(密钥不会出现在对话里)
2. 生成**授权链接**给你 → 你在浏览器点一下「同意」
3. 拿回调换取长期令牌,存到本机(以后自动续期,不用你再管)
4. **先拿一个小任务试点**,确认云端能不能读到项目代码 ——
   - 能 → 以后大活可以直接批量排队
   - 不能 → 云端只做"不需要本机环境"的活,**改代码仍然走本机助理那条通道**(一样能排队,只是不经过鼠标)

## 常见坑(提前说)

- **审核没过 / 状态一直「审核中」** → 告诉我就行,我看能不能查到原因
- **回调地址必须和填的一字不差** ✓(差一个字符授权就会失败)
- **access_token 有效期**官方文档自己有两处说法(1 小时 / 24 小时)→ 我不依赖它,**从第一天就用 refresh_token 自动续**,不受影响
- 配额(QPS / 任务数上限)官方没公开 → 所以我会**先小批量试**,不一次压太多
