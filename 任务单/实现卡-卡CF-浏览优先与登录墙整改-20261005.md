# 卡CF：小程序「浏览优先」整改（微信审核驳回：打开即要求登录）

> 模式：**代码开发**。基线 HEAD = `a062749`（开工前先 `git log --oneline -1` 核对）。
> 一张卡只做「改 + 最小自测」；验收判据见文末，**未验收不勾完成**。

## 为什么要做

微信审核驳回原文：「小程序打开一进入【微信一键登录】页面，未浏览体验功能服务，即要求授权手机号码、头像、昵称进行授权登录，请在用户体验浏览功能服务后，再自行选择授权登录。」

整改目标：**打开小程序 = 首页**，未登录也能浏览 首页 / 商品列表 / 商品详情（价格沿用卡AA 脱敏口径，不给真价）；只有在用户**主动**点「AI下单 / 订单 / 我的 / 加购下单」时才引导登录或注册。

⚠️ 全仓本来就没有 `getUserProfile` / `getPhoneNumber` / `chooseAvatar`（手机号是注册表单手填）—— **不许新增任何隐私授权接口**；本次只解决「入口是登录墙」。

## 改动清单（白名单：只许动下列 11 个文件）

### 前端

1. **`frontend/src/pages.json`**：把 `{ "path": "pages/buyer/home", ... }` 这一条挪到 `pages` 数组**第一位**（＝启动页）。其余条目顺序与内容一字不动（`pages/login/index` 保留在数组里，只是不再是第一条）。

2. **`frontend/src/App.vue`**：
   - 删掉 `onShow` 里「无 token → reLaunch 登录页」整段（现 90-98 行）；
   - 改为启动时调一次已有的 `autoLogin()`（静默补登，微信静默登录、**不弹任何授权框**）：成功 → 写 token/currentRole/accountStatus，若 `currentRole` 是 `supplier`/`courier` 则按现有 `routeToRoleHome()` 跳各自首页；失败 → **完全静默**（不跳页、不 toast、不 console.error 刷屏）；
   - `autoLogin()` 本身、dev 浮窗注入逻辑、样式段都不许动。

3. **`frontend/src/api/request.js`**：
   - 删掉 `if (!uni.getStorageSync('token') && url !== '/auth/wx-login') { reLaunch 登录页; reject }` 整段（现 93-98 行）—— 未登录也照常发请求（浏览类接口后端已放行）；
   - `statusCode === 401 || body.code === 2001` 分支（现 45-51 行）：清凭据后**不再** `reLaunch` 登录页；改为调一次 `getApp()?.globalData?.relogin?.()` 静默补登（补登内部会重新发请求，这里仍按原样 reject）；补登不可用/失败时只走既有 3 秒去重的 toast（文案「登录已过期，请重新进入」），并 reject；
   - 其余分支（业务错误 toast、HTTP 非 2xx 处理、`get/post/put/del` 导出）一字不动。

4. **`frontend/src/components/BuyerTabBar.vue`**：`refreshCart()` 开头加「`if (!uni.getStorageSync('token')) { cartCount.value = 0; return }`」—— 未登录不发 `/cart` 请求（未登录时角标为 0，不显示）。

5. **`frontend/src/pages/login/index.vue`**：
   - 登录区新增一行「**先逛逛，暂不登录 ›**」→ `uni.reLaunch({ url: '/pages/buyer/home' })`；
   - 保留「微信一键登录」按钮、「还没有账号？注册 ›」、「登录即代表同意《用户协议》《隐私政策》」三处一字不动；
   - **不许**在这里加任何 `getUserProfile` / `getPhoneNumber`。

6. **`frontend/src/pages/buyer/cart.vue` / `order-list.vue` / `mine.vue`**：
   - `onShow` 开头分支：
     - 无 token（未登录）→ 渲染**未登录空态**：「登录后可查看」+ 按钮「去登录」（`navigateTo /pages/login/index`）；**不请求任何接口、不自动跳转**；
     - 有 token 但 `accountStatus !== 2`（未注册/待审核）→ 渲染**账号未通过空态**：文案「账号注册并审核通过后可用」+ 按钮「去注册」（`navigateTo /pages/buyer/register`）；不请求需要身份的业务接口（`/cart`、`/order`）；`guardBuyerSuspended()` 保留原样；
     - 已注册 (`accountStatus === 2`) → 走现有逻辑，一字不改；
   - 空态样式沿用本页既有空态样式（`.xxx-empty` / 居中灰字 + 主色按钮），**不新造视觉**；
   - `mine.vue` 的未登录空态同样给出「去登录」按钮。

7. **`frontend/src/pages/buyer/home.vue` / `goods.vue` / `goods-detail.vue`**：
   - 无 token 时**跳过** `authApi.getProfile()` 与需要身份的请求（home 跳过 `loadOrders`、goods 跳过 `syncFromServer`），商品内容照常渲染（`getHomeContent` / `list` / `detail` 现在匿名可调）；
   - 价格位继续按 `priceVisible === false` 渲染 `¥**` + 灰字引导（后端匿名一律回 `priceVisible:false`，前端**不要自己造可见性判断**）；
   - 其余区块与逻辑（首页 7 块含 8 宫格、商品页分类栏/搜索、详情页主图 1:1、FAB、轮询器、`onShow` 刷新、`uni.$emit('cart-badge-refresh')`）一个都不许删。

### 后端

8. **`backend/src/modules/product/product.controller.ts`**：删掉 `categories` / `list` / `:id` 三处的 `@Roles(...)` 装饰器行（＝免登录可读）。`@CurrentUser('userId')` 保留，类型放宽为 `bigint | undefined`（写成 `userId?: bigint`）。

9. **`backend/src/modules/buyer/buyer.controller.ts`**：删掉 `GET home-content` 上的 `@Roles(...)` 一行；该文件**其它接口的 `@Roles` 一行都不许动**（register/pending/appeal/aftersale/bill/order/account… 全部继续要登录）。

10. **`backend/src/modules/product/product.service.ts`**：`priceVisibleFor(userId)` 开头加 `if (!userId) return false`（匿名一律脱敏）；`list` / `detail` 的 `userId` 参数类型放宽为可选。**价格可见性口径一个字节都不许改**。

11. **`backend/src/modules/buyer/buyer.service.ts`**：`getHomeContent` 同口径——无 `userId` 时推荐位一律 `salePrice: null` + `priceVisible: false`（有 userId 时走现有逻辑）。
