# 绿立方 · 设计规范（从 HTML 原型提取）

> 与 `src/styles/tokens.scss` 严格对应。原型基准宽度 375px（1px = 2rpx）。

## 一、配色

### 品牌与功能色

| 变量 | 色值 | 用途 |
|---|---|---|
| `$brand` | `#00B96B` | 主按钮、tab 高亮、品牌强调 |
| `$brand-deep` | `#00B578` | 价格绿、可点文字、成功态 |
| `$danger` | `#FA5151` | 驳回/拒收/删除/错误 |
| `$warn` | `#FF8F1F` | 待处理/变更中/库存预警 |
| `$info` | `#3B7CFF` | 链接/快捷操作/配送中 |
| `$link` | `#1677FF` | 次级操作文字 |

### 软色底（图标底、标签底，与功能色一一配对）

| 变量 | 色值 | 配对 |
|---|---|---|
| `$brand-soft` | `#E6F9F0` | 绿（成功标签、图标底） |
| `$warn-soft` | `#FFF3E6` | 橙 |
| `$danger-soft` | `#FFEDED` | 红 |
| `$info-soft` | `#E8F1FF` | 蓝 |

### 文字与背景

| 变量 | 色值 | 用途 |
|---|---|---|
| `$text-title` | `#1A1A1A` | 大标题 |
| `$text-body` | `#4A5261` | 正文 |
| `$text-second` | `#8A9099` | 次要说明（使用频率最高） |
| `$text-placeholder` | `#9AA1AB` | 占位符 |
| `$bg-page` | `#F5F6F8` | 页面底色 |
| `$bg-card` | `#FFFFFF` | 卡片 |
| `$bg-soft` | `#F7F9FA` | 输入框/浅底块 |
| `$border` | `#E4E7EB` | 常规边框 |

## 二、字号

| 变量 | 值 | 用途 |
|---|---|---|
| `$font-xs` | 10px | 角标、标签微字 |
| `$font-sm` | 12px | 说明、标签、chips |
| `$font-base` | 13px | 正文默认 |
| `$font-md` | 15px | 列表标题 |
| `$font-lg` | 17px | 页面标题 |
| `$font-xl` | 20px | 金额、大标题 |
| `$font-price` | 18px | 价格（红色 #FA5151 粗体） |

## 三、圆角 / 间距 / 阴影

- 圆角：标签与按钮 `999px`（胶囊）；卡片 `12px`；输入框/小按钮 `8px`；小标签 `4px`
- 间距步进：4 / 8 / 12 / 16 / 20（卡片内边距 12，卡片间距 12，页面左右边距 12）
- 卡片阴影：`0 1px 4px rgba(26,26,26,0.06)`

## 四、组件类名速查（common.scss，与原型同名）

| 类名 | 原型对应 | 说明 |
|---|---|---|
| `.page` | .page | 页面容器（底色 + 边距） |
| `.card` / `.card-title` | .card | 白卡片 |
| `.notice` | .notice | ⚠️ 黄底权限边界/规则提示条（每端必备） |
| `.list-item` + `.li-ico/.li-main/.li-t/.li-d` | 同名 | 图标 + 主文 + 状态标签的列表行 |
| `.tag` + `.g/.o/.r/.b` | 同名 | 状态标签四色 |
| `.chip-group` / `.chip.on` | 同名 | 筛选 chips |
| `.form-row` + `.fr-l/.fr-r` | 同名 | 表单行（label 左、内容右） |
| `.ipt` | 同名 | 输入框 |
| `.pbtn` + `.primary/.danger/.ghost` | 同名 | 按钮 |
| `.row-btns` | 同名 | 按钮行（flex 平分） |
| `.grid-btns` + `.gbtn/.gi/.gt` | 同名 | 九宫格快捷入口 |
| `.stepper` + `.st-btn/.st-num` | 步进器 | − 数量 ＋ |
| `.price` / `.muted` | — | 红色价格 / 灰色说明 |

## 五、状态色语义约定

| 状态 | 标签 |
|---|---|
| 在售 / 已完成 / 已生效 / 接受 | `.tag.g` |
| 待审核 / 变更审核中 / 备货中 | `.tag.o` |
| 已驳回 / 异常 / 拒收 / 已删除 | `.tag.r` |
| 配送中 / 信息类 / 进行中 | `.tag.b` |
