## 要画几屏（每屏一个手机壳；一行放不下就分两行，但**每行要完整、不许折行错位**）

| 屏 | 内容 |
|---|---|
| ① | **商品管理页（改造后）**：每行左侧**真实封面缩略图**（现状是 emoji 图标 🥬📦，要换成真照片；缩略图右下角一个小相机角标 → 暗示"点它可换图"）；每行按钮区：「✏️ 编辑」「⚡ 改库存」+ **新增「下架」** |
| ② | **点封面 → 底部弹出选择**：**拍照 / 从相册选择 / 取消** |
| ③ | **上传中 + 完成**：转圈「上传中…」→ 完成提示「封面已更新（已生效）」；该行缩略图已换成新图 |
| ④ | **点「下架」→ 底部确认抽屉**：「下架后买家看不到这个菜；**历史订单不受影响**，随时可以重新上架」+ 按钮「确认下架」「取消」 |
| ⑤ | **下架后的行**：状态标签变「已下架」，按钮变「**重新上架**」（编辑 / 改库存仍可用） |
| ⑥ | **被驳回的申请**：该行按钮是「**删除**」→ 确认弹窗「删除后无法恢复（这条申请会被撤掉）」→ 删除后该行消失 |
| ⑦ | **「提交新商品」表单（改造后）**：封面区（点击选图 + 已选缩略图）+ 「资质证明」区（点击上传，可多张、可查看/删除）—— 现状这一行是**点不动的死文案** |

## 每屏下面必须标一行「对应实现（接口 / 文件）」

- 换封面：`POST /upload/image`（前端先压缩）→ 写 `product.cover`；新接口 `PUT /supplier-goods/:id/cover`（免审即时 + 留痕）
- 下架 / 上架：新接口 `PUT /supplier-goods/:id/status`（0 下架 / 1 上架，免审即时 + 留痕）
- 删除申请：新接口 `DELETE /supplier-goods/apply/:applyId`（**仅限待审核 / 已驳回**的自建申请）
- 资质证明：复用 `POST /supplier-goods/apply` 的 `images` 字段（后端已有）

## 红线要直接写在图上

- 🟢 免审即时：**换封面**、**下架**、**重新上架**、改日可供量
- 🟠 走审核：改价 / 改名 / 上新品
- 🔴 **正式在售商品不许删除**（订单引用过它，删了运营的账就空了）—— 只能下架；只有**被驳回 / 还在审核**的自建申请能删

## 出图要求

- 单文件 HTML，**无外部依赖**（不要 CDN；图标用 emoji 或纯 CSS）。
- 手机壳宽度 320px；**视口宽度按「手机宽 × 屏数 + 间距」定**，屏多了宁可分两行也别让某一屏被裁切。
- 用**你自己带的 `playwright-cli`** 出 PNG（🚫 不要用 agent-browser，在你这台机器上会卡死）：临时目录起 `python -m http.server 8899 --bind 127.0.0.1` → 打开页面 → 截图时**只截手机壳那一行容器**（别整页截，会把标题和滚动条一起带上）→ 用完把 http 服务停掉。
- 交付：HTML + PNG 两个文件（PNG 给大辉看；他主要看图，不看代码）。
