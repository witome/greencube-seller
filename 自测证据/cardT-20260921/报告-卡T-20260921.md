## 8. 过程中发现并处理的环境问题（请 Hermes 留意）

1. **原先跑在 3001 的后端是 9/12 启动的旧 `nest start --watch` 实例**，它的 TS 程序缓存着「Prisma Client 尚未 generate」时的类型，导致每次重编译都报 **307 个 `Property 'xxx' does not exist on type 'PrismaService'`**，**编译不通过 → 新代码永远加载不进去**。
   处理：`node node_modules/@nestjs/cli/bin/nest.js build`（**全新进程，0 错误，构建成功**）后 `node dist/main` 重启。**结论：这不是代码错误，是那个老 watch 进程的缓存问题；重启实例后 `nest build` 干净通过。**
   ⚠️ 遗留提醒：如果之后又用 `bash 重启后端.sh` 起 watch，**新进程不会再带这个缓存**，应该正常；但若再见到那 307 个错，请先怀疑 watch 进程老化，别怀疑代码。
2. 本机 Bash 工具本次会话 PATH 未初始化（`dirname: command not found` → 连带 `ls/head/node` 全找不到）。命令开头补 `export PATH=...` 即恢复，与项目无关。
