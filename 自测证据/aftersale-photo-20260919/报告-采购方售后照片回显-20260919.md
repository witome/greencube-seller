### 1.2 前端 · 复用而非另起一套

| 复用点 | 来源 | 做法 |
|---|---|---|
| 缩略图结构 | `pages/buyer/aftersale.vue:26-31` | 同一套 `.photo-grid` / `.photo-item` / `.photo-img`（**类名与 72×72 / 圆角 8px 尺寸逐字一致**） |
| URL 拼接 | `api/request.js` 的 `fullUrl()` | 与申请页同一个函数，页面里不重复拼 host |
| 预览逻辑 | **新增到** `utils/photo-upload.js` | 上一张卡建的共享照片工具；H5 侧此前全仓**没有任何** `previewImage` 用法，故收口在此，避免两个页面各写一套 |

```js
export function previewPhotos(paths, current) {
  const urls = (paths || []).map((p) => fullUrl(p)).filter(Boolean)
  if (!urls.length) return
  const cur = fullUrl(current) || urls[0]
  uni.previewImage({ urls, current: cur })
}
```

列表页模板（`aftersale-list.vue`）——**有照片才渲染**，无照片的行连容器都不出现：

```vue
<view v-if="(a.attachments || []).length" class="photo-grid">
  <view v-for="(p, i) in a.attachments" :key="i" class="photo-item" @tap="viewPhotos(a.attachments, p)">
    <image :src="fullUrl(p)" mode="aspectFill" class="photo-img" />
  </view>
</view>
<view v-if="(a.attachments || []).length" class="photo-tip">已上传 {{ a.attachments.length }} 张，点图看大图</view>
```

**只读展示**：没有新增任何提交/修改入口，申请流程（`pages/buyer/aftersale.vue`）一行未动。
